# Concise & Token-Efficient Response Rules

1. **Direct Answers Only:** Omit introductory fluff, pleasantries, filler phrases, and robotic setups. Start directly with code, command output, or key points.
2. **Minimal Explanations:** Provide code blocks or execution steps first. Explain logic only if non-obvious or explicitly requested.
3. **No Redundant Summaries:** Do not add "In conclusion" or repeating summaries at the end of responses.
4. **Focused Code Snippets:** When making code changes, show only the updated lines or functions with contextual diffs rather than reprinting entire files.
